Palettium v0038 — GDI-owned PDEVICE publication and screen metrics

Apply over the user-validated v0037 tree:
  cd ~/dev/palettium
  unzip -o ~/Downloads/pal38.zip

Changes:
* Added pal_screen_host_gdi_snapshot(): a live/identity-checked, pure
  PDEVICE image for GDI-owned storage; rejects stopped host, wrong token,
  malformed PDEVICE and mismatched DDI without touching the hardware.
* Win16 pal_win16_publish_host() replaces the old unchecked bind_host
  placeholder. It computes the actual far pointer token from GDI's
  destination, rejects 64-KiB segment overflow, copies the validated
  20-byte PDEVICE as FAR bytes, and exposes the host only after the copy.
  Disable refuses unrelated PDEVICE pointers. This helper is dormant.
* The Win3.1 110-byte GDIINFO candidate now reports coherent 96-DPI
  screen dimensions, aspect ratios and metric/English/twips scaling.
  Unsupported capability bits remain zero; not installable.
* Extended ET4000AX banked-screen tests for PDEVICE publication and
  bounds, new GDIINFO metric checks, make test runs GDIINFO regression,
  and maintenance asserts unchecked binding cannot reappear.
