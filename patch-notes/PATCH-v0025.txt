Palettium v0025 — Win3.x INDEX8 palette + ColorInfo/ScanLR + DDI palette exports

Base: apply over v0024 from pal24.zip, inside the palettium repository root.

New shared color engine
- include/rg_palette.h, common/rg_palette.c: initial 20 Windows 3.x
  reserved RGB entries (0..9,246..255), 236 mutable slots, identity
  logical->physical mapping and deterministic inverse; ColorInfo RGB/index
  conversions (0x00BBGGRR and 0xFF00iiii), dynamic palette remap.
- Refuses mutation of the 20 static colors; bulk translations are checked
  before commit, including preserving static indices. Pixel remaps validate
  all input indices and geometry before writing, and use RG_Ops pixel.
- No chipset-specific logic or Win16 far pointers in this shared component.

Win3.1 integration
- palddi.c: ColorInfo @2, ScanLR @12, SetPalette @22, GetPalette @23,
  SetPalTrans @24, GetPalTrans @25, UpdateColors @26.
- Proper Win16 FAR PASCAL signatures; far-pointer copying stays in adapter.
  Palette DDI functions are inactive until the screen host is running.
- Screen host initializes 20 Windows static DAC entries via RG_Hardware's
  palette hook when starting an INDEX8 screen, and tracks later changes.
  ET4000AX converts 8-bit components to its 6-bit DAC as before.
- ScanLR uses physical INDEX8 pixels, returns the matching/nonmatching
  coordinate (or -1), refuses foreign device identity and bad coordinates.
- No new production Win31 DDI file or redundant hardware implementation.

Tests and maintenance
- Host C89 palette tests: static/dynamic entries, nearest-color matching,
  index marker, logical/physical translation, inverse, invalid maps,
  UpdateColors bounds and hardware override.
- ET4000AX hardware screen test: static palette DAC initialization,
  ColorInfo, ScanLR, UpdateColors across 64 KiB banks, hardware lifecycle.
- 12-ordinal Win16 export checker and known-bad-input tests.
- Avoid tautological >65535 comparisons in Open Watcom 16-bit unsigned
  parameter cases using UINT_MAX; original host-side rejection remains.
- Updated top-level README.md and windows/win31/README.md to actual status.

NOT INSTALLABLE. Enable(style=0) remains disabled. Candidate GDIINFO does not
advertise RC_PALETTE; the needed device-object, bitmap, text, cursor and
mode-start interfaces are incomplete. Do not modify Windows' SYSTEM.INI.
